# winget manifests

`manifests/d/DeltaFStudio/DeltaFStudio/<version>/` mirrors the layout of
[microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs). Only the
first version is kept here, to submit it by hand; later versions are
written and submitted by the `winget` job of the Release workflow. See
[docs/STORE_AND_WINGET.md](../../docs/STORE_AND_WINGET.md).
